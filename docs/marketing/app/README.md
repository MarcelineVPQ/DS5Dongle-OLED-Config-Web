# App screenshots (marketing)

Full-resolution (2x) screenshots of the desktop app, taken live with a Cosmic
Red DualSense on firmware v0.8 (the 0.8 layout). The guide's own screenshots
are in `docs/screenshots/`, taken in one fixed look with `tools/screenshot_env.mjs`.

| File | Shows |
| --- | --- |
| `hero-live-controller.png` | The hero shot: the live controller full width (panel hidden), tiles and live data |
| `live-controller.png` | The start view with the settings list |
| `panel-lightbar.png`, `panel-trigger.png`, `panel-remap.png`, `panel-dongle.png` | Settings panels |
| `tour.png` | The first-run guided tour |
| `live-data.png` | Close-up of the live data cards |
| `about-credits.png` | About → Credits (42 Pixel Studios) |

Not included on purpose: the PS (pairing slots) panel, which shows controller
Bluetooth addresses, and the Games page, which lists the local game library.

Colorway renders and the animation are in `../colorways/`.
