# Glossary: Sony's names for the controller

The app names controller parts and settings the way Sony does, in each of its 7 languages. When a string names a part of the DualSense or DualSense Edge, use the term in this table (adjust case and grammar to fit the sentence). Our own features keep our names: **Audio Auto Haptics**, pairing **slots 0–3**, **FAV0–FAV3**, button **layouts**, game **profiles** (not to be confused with the Edge's custom profiles).

Collected from Sony's own pages on 2026-10-13. The old PS5 user's guide (`manuals.playstation.net`) now redirects to the playstation.com support pages, so those are the source.

## Where we use our own wording

⚠ marks a term with no Sony page in that language. In those cases:

- **Motion sensor (de, fr):** no DualSense page names it; the terms come from Sony's DUALSHOCK 4 page. "Capteurs de mouvement" is our wording.
- **PS5 menu path (de, fr):** "Controller (Allgemein)" and "Manette (général)" follow Sony's pattern; we didn't see the exact menu string.
- **Trigger stops (de, fr):** the support page is served in English; the terms are from Sony's PlayStation Blog posts.
- **Trigger deadzone (es):** Sony's menu says "Activar zona muerta", a mistranslation ("Trigger" read as a verb). We use "Zona muerta de los gatillos" from Sony's own headings.
- **Directional buttons, one by one:** Sony names the group only. We write **Up button / Down button / Left button / Right button** in English, and the group name plus the direction elsewhere (Richtungstaste oben, Touche directionnelle haut, 方向キー上…).
- **L1, R1, L2, R2 and △ ○ ✕ □:** kept short as on the controller. Sony's pages say "L2 button", "triangle button" in running text.
- **Grips:** Sony has no name for the grips as a setting. The haptics panel is called **Haptic feedback**, and its sliders **Vibration intensity (left / right)**.
- **Curve presets:** our Precise, Steady and Digital match Sony's. Our **Aggressive** became Sony's **Quick** (it is the same quick start). Our **Linear** and **Custom** have no Sony equivalent and keep their names; Sony's **Dynamic** has no counterpart in the app.
- **Battery level:** no Sony string in any language; we keep our own ("Battery").
- **Charge states (Charging, Fully charged, Plugged in, not charging):** Sony's pages describe charging only in running text (the light bar pulses orange), with no status labels; the wording is our own.
- **Inconsistent at Sony:** zh-CN uses 振动 (console) and 震动 (Edge); we use 振动. ja uses プレーヤーランプ and プレイヤーランプ; we use プレーヤーランプ. pt-BR uses "Manípulo" in the part list and "analógico" everywhere else; we use "analógico". de uses "Deadzone" in menus and "Totzone" in marketing; we use "Deadzone".

## Naming the board

The app never says "dongle" (that is the owner's slang) in any language. Every string that names the board uses the `{{device…}}` variables (`src/i18n/deviceForms.ts`): the board the firmware reports ("the Pico 2 W"), the last board that connected while none is, and **your board** before any has (Dein Board, ta carte, tu placa, sua placa, 你的开发板, お使いのボード). `{{deviceName}}` is the bare name for headings and labels ("Pico 2 W" / "Your board"), `{{device, capitalize}}` starts a sentence, and languages with articles or cases have one variable per grammatical spot (German `device_dat`, French `device_de`…). The board's page is named after the board in the side bar, and the save button reads **Save to the Pico 2 W**. Only the product's own name keeps the word: **DS5 Dongle OLED Edition**, and the firmware's USB name "DS5 Dongle Wake Keyboard". `tests/unit/deviceWording.test.ts` fails if a translation says "dongle" again.

## The OLED screen

The firmware's OLED screens use short words that differ from Sony's, because the screen is 128 pixels wide. They're not changed here (firmware strings are out of scope): "Lightbar" (Sony: light bar), "Touchpad" (touch pad), "Gyro Tilt" (gyroscope), "HAP" (haptic feedback), "SPK" (speaker), "BT Mic" (built-in microphone), "DP nav" (directional buttons), "Tri=" (triangle button), "Hold Create + PS" (the Create button and the PS button).

The Settings screen's entries since firmware dev.9 (`src/oled.cpp`, `format_settings_item`) are short forms too: "TrigEff" (Trigger Effect Intensity; "game" at 0, else "-1".."-10"), "SpkBoost" (Speaker boost; "game" or 1..7), "VolLock" (Lock volume), "SPK Out" (Audio output: Auto, SPK, Hset, off), "Mic In" (Microphone used: Auto, Int, Hset), "Sleep CtrlOff" (Turn off the controller when the PC sleeps) and "PS Wakes PC" (Wake the PC with the PS button). The Status pin is set from the app only. Aligning the OLED with Sony's words is a backlog row ("OLED screens use Sony's names").
