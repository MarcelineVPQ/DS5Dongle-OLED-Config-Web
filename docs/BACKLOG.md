# DS5 Dongle OLED Edition Backlog

**The one list** of open and planned work for the app and its firmware (`~/projects/DS5Dongle`
points here too), started 2026-10-11. Each row says what it is, where it stands, and what it is
waiting on. Rows with a detail doc link to it.

**Keeping it current:**

- When work starts, ships, or is decided against, change its row in the same commit. A shipped
  item moves to the **Shipped** table with a **Done** status that names the build it is in (or
  "unreleased" until a build has it). It stays there while About → Coming soon lists it under "In
  the next build" (`tests/unit/roadmapBacklog.test.ts` maps every entry to a row and checks its
  status), and both leave once it is in a stable release (the CHANGELOG has it); its detail doc
  (if any) then moves to `docs/complete/`.
- Something agreed in conversation gets a row the same day.
- Session notes and handoffs point here. They never keep a second list.
- **The app shows a public copy of this list** (About → Coming soon, `src/desktop/about/roadmap.ts`).
  When a user-facing row is added, changes status, ships or is dropped, update its entry there in
  the same commit (plain, short, no dates; never internal details, hosts, names, telemetry or the
  easter egg). "In the next build" entries leave it once they're in a stable release.
- **Both ways:** every row still to do (any status but Done / Fixed / Superseded) has a Coming
  soon entry, unless it's internal: then its Item cell ends with **(internal)** (tooling, tests,
  hosting, naming, marketing, other people's bugs, anything a user never sees). An internal row
  has no entry. `tests/unit/roadmapBacklog.test.ts` checks both directions.

**Status words:** _Agreed_ (decided, not started) · _In progress_ · _Blocked_ (waiting on
something outside the project) · _Question_ (needs an answer from Marcy before anything happens) ·
_Idea_ (noted, not decided) · _Open_ (a known problem, not yet scheduled) · _Done_ (shipped: in a
Development build, or merged for the next one) · _Superseded_ (replaced by later work).
